# 独立 Reflow 源码公开预览方案

此页保留首次公开方案。2026-10-28 已按用户授权创建 [公开仓库](https://github.com/chatwithgod/reflow)，先推送审阅提交 `d5fea7d`，随后修复首轮 CI 暴露的路径断言并通过三平台复核。实际执行与边界见 [公开记录](PUBLICATION-2026-10-28.md)。二进制 Release、商店、上游 PR 和 OSS 申请尚未执行。

## 拟执行的范围

拟在 `chatwithgod` 名下新建公开仓库 `reflow`，推送审阅时固定的本地 `main` 提交及其历史，作为开发预览源码。模块路径已经使用 `github.com/chatwithgod/reflow`。创建时若仓库已存在或账号不符，先停止核对，不覆盖现有仓库、不强制推送。

首次推送将触发仓库已有的离线 GitHub Actions 流水线，运行 Windows、Linux、macOS 的 Go 回归、race、vet、fuzz 和评测进程自检。流水线不含真实模型凭据；未配置原生客户端路径的四项客户端测试会跳过。因此即便通过，也不能代替真实登录或 Desktop/dot 验收。

这一步的对外动作只有公开源码和自动离线 CI。二进制 Release、插件商店、Magpie 上游 PR 和 OSS 申请分别处理。现有 CPA 仓库与本机生产配置不属于这次变更。

## 审阅包

本地审阅目录保存三类文件：

- 固定提交的源码 ZIP：只包含 Git 跟踪的文件，不包含 `.tools`、临时账号、开发缓存或构建目录；其中 `dist/go.mod` 仅用于排除生成目录的重复测试。
- 审阅清单：记录源码提交、ZIP 散列、历史对象核对结果、文件列表及许可文件。
- 已有 dev.4 构件的校验记录：沿用原来的十个 ZIP，不覆盖或重建。它们带有生成时的文档，最新状态以本次源码快照为准；这次公开源码不会自动上传这些构件。

源码审阅清单由本地准备流程生成在 `build/publication/` 下。推送前应核对清单中的提交仍是待推送提交；如果源码有后续修改，应重新生成供用户审阅。
