# Reflow 开源准备与证据

Reflow 已从 CPA 插件提取为独立核心，并为 Codex CLI、Pi 和 Magpie 准备了接入方式。[独立源码](https://github.com/chatwithgod/reflow)已于 2026-10-28 公开，三平台离线 CI 通过；尚未发布二进制 Release。已有原生登录的有限实测，尚无质量改善结论或已验证的外部用户反馈数据。

## 计划定位

[Codex for Open Source 官方说明](https://developers.openai.com/community/codex-for-oss)（2026-10-27 重新核对）面向核心维护者和广泛使用的公开项目，也允许其他项目解释其生态价值。支持内容包括六个月 ChatGPT Pro with Codex、按条件提供的 Codex Security，以及用于核心开源工作的 API 额度；页面明确支持 Pi 等其他客户端。

工程判断是：跨生态适配能拓宽 Reflow 的用途，但不是计划的官方先决条件，也不保证入选。申请时应说明已经解决的维护问题、可复现结果及后续维护用途，不把本地适配数量写成社区采用量。

已按 [官方申请表](https://openai.com/form/codex-for-oss/) 的三段 500 字符限制准备 [申请草稿](OSS-APPLICATION-DRAFT.md)，并补入真实公开仓库及 CI 链接。个人信息与支持项目选择仍未填写，也未提交申请。

独立仓库已按 [源码预览方案](PUBLICATION-PLAN.md)完成首次公开，见 [执行与 CI 记录](PUBLICATION-2026-10-28.md)。正式 Release、商店、上游 PR 和申请分别处理。

修复版在 2026-10-27 的 NDJSON 和后续拓扑排序真实诊断中均正常完成，分别评分 9/9 和 8/8，工具失败事件为 0；两次都没有触发续接。2026-10-29，未修改的官方 `0.165.0` 又完成 NDJSON 和 LRU 的单次诊断，评分均为 9/9，分别为 6 次和 5 次推理请求、续接均为 0；两次各有一次命令失败，随后完成任务。该阶段累计为 9 次会话、51 次推理请求、1 次续接。见 [LRU 证据](LIVE-LRU-2026-10-29.md)与[此前 NDJSON 记录](LIVE-OFFICIAL-0165-2026-10-29.md)。

[官方 API 检查](LIVE-API-KEY-2026-10-29.md)单列为 1 次会话、2 次请求、0 次续接；其实际用量和单价估算不作为 ChatGPT 订阅费用或后续 API 预算的依据。该临时 key 已结束使用，不参与后续准备。

[Ubuntu 第四轮对照](LINUX-SANDBOX-CONTROL.md)证明了固定发行版配置在同一 runner 上使原有五个写入场景从 0/5 变为 5/5；文件/网络边界、配置移除及直接命令反向检查通过。成功依赖明确授权的 ABI 告警例外，默认自动流水线的失败保持可见。这是可复现的宿主兼容性排查证据，不等同于真实账号或所有 Linux 环境验收。

Windows 原生文件编辑探针曾在两版官方 CLI 中失败，已定位到 helper 遗漏 `SYSTEMROOT`，并找到 OpenAI 已合并的修复。加入该修复的本地源码构件通过了五个写入场景及原生协议、插件回归。保存的复现和上游回移补丁属于兼容性排查证据，不能算作本项目新提交的上游修复；也不能当作官方版本或真实账号整体验收。该探针独立于默认回归。见 [离线复现](NATIVE-WRITE-PROBE.md)。

## 后续顺序

Ubuntu 对照和 LRU 证据已公开。最新维护任务已观察到续接与正常结束，接下来先离线核对工具错误输出和成功关联证据。新增真实调用仍须单独授权；不因小任务没有触发续接自动重跑，也不修改判定阈值来制造通过结果。只比较完整成对结果；没有观察到续接时保留未验收。Desktop/dot 按用户决定暂留未验收，待方便时单独安排。

公开仓库截至 `d0f1be6` 的推送已按授权完成；本轮新增对账任务、事件诊断与真实记录仍在本地，尚未推送。二进制发布、提交上游 PR、商店上架和提交申请，也分别取得相应授权后执行。现有 CPA/ECPA/Codex 生产配置保持不变。
