# Reflow 开源准备与证据

Reflow 已从 CPA 插件提取为独立核心，并提供 Codex CLI、Codex 插件、Pi 和外置 Magpie 接入。[源码](https://github.com/chatwithgod/reflow)于 2026-10-28 公开；2026-10-31 发布了固定 `3e0ea18` 的 [dev.5 预发布版](https://github.com/chatwithgod/reflow/releases/tag/v0.1.0-dev.5)。五平台共 10 个服务/插件 ZIP、12 个附件的公开下载散列全部核对通过。已有有限原生登录功能实测，尚无质量改善结论或已验证的外部采用数据。

## 申请定位

2026-10-31 重新核对的 [Codex for Open Source 官方说明](https://developers.openai.com/community/codex-for-oss)支持维护者申请六个月 ChatGPT Pro with Codex，并按条件提供 Codex Security 和核心开源工作所需的 API 额度；页面也支持 Pi 等其他客户端。规模较小的项目可以解释其生态价值，选择结果由项目方审查。

当前适合说明的价值是：把预算受限的续接、工具隔离、用量合并、取消和历史恢复做成共享实现，并用可复现检查维护多个客户端与网关的兼容性。跨生态适配数量、测试通过项和发布核验下载都不等于社区采用量，也不构成入选保证。

[申请草稿](OSS-APPLICATION-DRAFT.md)和[结构化文本](oss-application-fields.json)已按官方申请表的 500 字符限制更新，三段分别为 471、373、453 字符。姓名、ChatGPT 账号邮箱、申请身份和支持选项仍需用户提供或确认；尚未填写网页或提交申请。

## 维护工作如何归因

原生登录累计为 21 次会话、114 次已观察请求、4 次续接；真实样本与配置审计例外见[验收总表](NATIVE-LOGIN-ACCEPTANCE.md)。此次发布和文档更新没有增加真实样本。官方 API 单列为一次会话、两次请求、零次续接，旧临时 key 不再使用。

Windows 文件编辑探针曾定位到 helper 遗漏 `SYSTEMROOT`，本地加入 OpenAI 已合并的修复后通过。这里可说明兼容性复现和验证工作，不能把上游已有修复记成本项目新提交的贡献。见[复现记录](NATIVE-WRITE-PROBE.md)。

此前获批的[Ubuntu 固定配置对照](LINUX-SANDBOX-CONTROL.md)在同一 runner 上得到写入 0/5 到 5/5，并验证边界与清理。它依赖明确的发行版配置和 ABI 告警例外；默认 CI 的失败保持可见，不能推广为所有 Linux 主机或本次所有发布构件均通过。

Magpie 的[外置接入](../adapters/magpie/EXTERNAL.md)使用既有账号指定接口；[账号隔离修复](evidence/magpie-external-account-scope-2026-10-31.json)和[完整外置链路证据](evidence/magpie-external-chain-2026-10-31.json)属于本项目。嵌入式宿主补丁保留为实验材料。已有 #4497 是接入设计讨论，宿主全量失败的排查笔记没有作为具体缺陷报告提交，不能写成已合并修复。

旧 CPA 版的发布、用户与贡献需要另行核实和归因，不能充当独立 Reflow 的采用数据。源码公开、二进制预发布、上游接受、社区采用和质量改善是不同证据。

## 后续范围

申请材料现在可以围绕公开代码、可下载构件、复现方法和真实维护过程供用户审阅。更有说服力的补充是实际用户问题、可复现反馈和后续修复记录；目前没有这些证据，不虚构或推算。

Desktop/dot 继续按用户决定保留未验收。Pi 已按模拟范围验收，不重新要求登录。原生真实测试的持续授权仍受并发 1、既定超时/预算和遇限流停止约束；生产接入、后续源码推送、发布、商店和正式申请按各步骤的实际授权处理。准备好申请草稿不代表完整工程 goal 已完成，也不代表已提交或获得支持。
