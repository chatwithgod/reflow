# Reflow 开源准备与证据

Reflow 已从 CPA 插件提取为独立核心，并为 Codex CLI、Pi 和 Magpie 准备了接入方式。当前是本地开发成果，尚未公开发布。已有原生登录的有限实测，尚无质量改善结论或外部用户反馈数据。

## 计划定位

[Codex for Open Source 官方说明](https://developers.openai.com/community/codex-for-oss)（2026-10-26 核对）面向核心维护者和广泛使用的公开项目，也允许其他项目解释其生态价值。支持内容包括六个月 ChatGPT Pro with Codex、按条件提供的 Codex Security，以及用于核心开源工作的 API 额度；页面明确支持 Pi 等其他客户端。

工程判断是：跨生态适配能拓宽 Reflow 的用途，但不是计划的官方先决条件，也不保证入选。申请时应说明已经解决的维护问题、可复现结果及后续维护用途，不把本地适配数量写成社区采用量。

## 当前证据

| 类别 | 已有成果 | 仍需补齐 |
| --- | --- | --- |
| 源码与构件 | 独立本地仓库；版本化构件与 SHA256；许可证及来源说明 | 公共仓库、发布链接及持续维护记录 |
| 功能回归 | 独立版源码范围 65 个通过项、0 跳过；race/vet/fuzz 通过；Codex/Pi/插件真实客户端配合模拟上游验收；本地 CI 草稿和评测自检入口 | 完整真实账号验收、Desktop/dot、其他系统原生运行、远程 CI 实际结果 |
| Magpie 贡献 | 独立 cgroup 修复、宿主执行扩展、可选桥接三份补丁；正向与反向验证 | 宿主既有失败的继续排查；上游 issue/PR、评审及处理结果 |
| 开关评测 | 4 任务、34 检查点评分器；NDJSON 有限实测与用量记录 | 开启组超时定位与复测、完整有效的配对结果 |
| 外部反馈 | 当前独立版没有已验证的采用数据 | 真实用户问题、复现、修复和反馈链接 |

具体兼容范围见 [兼容性说明](COMPATIBILITY.md)，验证散列和证据见 [dev.3 记录](VERIFICATION-0.1.0-dev.3.md)。旧 CPA 版的发布与使用情况应单独核实、单独列出，不能充当独立版的使用数据。

共享入口与 CI 范围见 [回归说明](REGRESSION.md)，Magpie 已知失败的源码线索见 [基准排查](../adapters/magpie/BASELINE-TRIAGE.md)。CI 草稿尚未对外执行，排查笔记尚未转化为上游 issue。

原生登录实测已经观察到一次续接，两个输出文件均通过 9/9 检查，但开启组会话超时，因此整体验收未完成。申请材料应同时写明这一限制，不能将局部成功写成全部通过。见 [实测记录](LIVE-SMOKE-2026-10-26.md)。

## 后续顺序

先在用户单独授权后，用真实账号运行隔离目录中的小规模连通与开关对照测试。只比较完整成对结果；没有观察到续接时，记录为未触发，不能据此宣布续接验收通过。随后单独安排 Desktop/dot 实际验收。

仓库文档、工作流草稿、发布说明和 PR 内容可先在本地准备。创建公共仓库、推送、发布、提交上游 PR、商店上架和提交申请，分别取得相应授权后再执行。现有 CPA/ECPA/Codex 生产配置保持不变。
