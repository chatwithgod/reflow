# 原生工具错误字段离线核对

2026-10-30，使用官方 Codex `0.165.0`、Reflow dev.4、合成登录和回环模拟上游核对工具事件。测试并发 1，真实模型调用 0。两项新探针普通和 race 均通过，原有直接 MCP 与 Code Mode 两项原生基线也分别通过普通和 race。

固定命令先写入临时工作区文件，再以退出码 1 结束。一个场景额外输出固定的 Python 断言标记，另一个不输出应用错误标记。两者都经过模拟续接，由实际原生客户端执行，并完成后续只读工具和结果回传；被舍弃轮的写入仍不得执行。

官方客户端确实提供 `aggregated_output`、`status` 和 `exit_code` 字段。把其事件在内存中交给真实 Python 分类器，带断言标记的场景得到 `python_assertion`，无应用标记的场景得到 `unclassified`。诊断字段没有读错，但这不能说明真实测试中的未分类命令是什么，也不能推定其输出为空。

最初夹具错误地要求静默命令的 `aggregated_output` 必须为空；实际仍包含宿主输出，因此该假设失败。修正仅移除了空字符串要求，退出码、固定标记、临时文件写入、舍弃轮隔离、工具回传和用量断言均保留。没有修改真实测试的评分或验收标准。

这是需要显式 `native_event_probe` 构建标签的诊断，不改变默认原生 CI 的任务数量。日志只记录固定标签、计数和长度。详细结果、来源散列及初次夹具失败说明见[数字记录](evidence/native-event-schema-2026-10-30.json)。
