## 新增验证范围

Magpie 内存适配复用同一个 HTTP 流处理与缓存，不新增监听端口，不接收账号凭据。独立包中的适配测试覆盖续接、账号范围隔离、完整历史重放和关闭响应时取消并回收工作协程。宿主四条路径、补丁和全量失败对照见 [Magpie 验证](../adapters/magpie/VERIFICATION.md)。

可选 `-metrics` 统计 Responses 上游原始终止事件，包含隐藏轮次，也可在续接关闭时统计。HTTP 和 WebSocket 测试核对重复终止事件、预热排除、异常用量和缺失报告；Codex/Pi 联调核对三次上游请求、一次续接及原始 token 总数。默认关闭，无账号、模型名、响应 ID 或正文，不写磁盘。`usage_complete=false` 时不能将已观察总量当作完整消耗；这不是金额统计。
