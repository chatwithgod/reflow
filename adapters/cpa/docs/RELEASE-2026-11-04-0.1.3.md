# v0.1.3 发布与验收记录（2026-11-04）

**已正式发布：** [CodexReflow v0.1.3](https://github.com/chatwithgod/cpa-plugin-codexreflow/releases/tag/v0.1.3)，2026-11-04 21:49:16（UTC+8）。GitHub 读回为 latest stable，包含五个平台 ZIP 和统一校验文件。

## 本版解决什么

修复 [Issue #2](https://github.com/chatwithgod/cpa-plugin-codexreflow/issues/2)：CPA 插件执行路径可能把 collaboration 工具参数从 `number` 改成 `integer`，导致上游在首轮就拒绝请求。

本版对照 `OriginalRequest`，仅还原匹配已知规整结果的类型变化，**保留多智能体工具**，不整体覆盖 CPA 的请求处理。覆盖顶层工具、分作用域的 `additional_tools`、HTTP/SSE、WS 和续接重放；原本为整数的参数不改。缺少或身份不明的原始声明不猜测修复。不新增用户配置，续接规则和预算不变。

## 实际验收结果

| 层级 | 结果与范围 |
|---|---|
| 五个平台 | 各通过 Go unit/race/vet、decoder/schema 各 15 秒 fuzz、48 项 Python 回归 |
| 原生库与 ZIP 解出库 | 每个平台各通过同一组 46 项 ABI 场景；每组五平台共 230 次执行，不是 460 种独立场景 |
| 同一 Windows 正式 DLL + CPA 8.0.13 | 23 项 HTTP/WS、13 项父 ID 衔接、14 项原生增量续接，共 50 项符合预期 |
| 同一 Windows 正式 DLL + CPA 8.0.47 | 18 项工具 schema 专项通过，含首轮、516 续接、动态声明、整数保留、WS 协作工具往返 |
| 同一 Windows 正式 DLL + CPA 8.0.53 | 2 项 HTTP/WS 工具专项及 2 项空/非空输入预热检查通过 |
| 公开下载 | 六个资产均匿名下载返回 HTTP 200；逐字节、SHA256、校验文件、ZIP 架构/CRC/动态库/许可证全部一致 |
| 公开 Windows 包 | 仅提取已验证的根 DLL，在独立进程再次通过同组 46 项离线 ABI 检查 |

Windows 集成合计 72 项隔离用例。使用独立 CPA 配置、空账号目录和本地模拟上游，没有额外真实模型测试请求。失败/取消边界的“通过”表示符合各自断言，不是要求所有模拟请求都成功。

Linux/macOS 的实际 CPA/客户端/模型集成、旧系统兼容性和 macOS 签名/公证没有因此获得验证；不据此宣称模型质量提高。
