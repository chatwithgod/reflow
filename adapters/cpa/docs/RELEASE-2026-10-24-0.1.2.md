# v0.1.2 发布与验收记录（2026-10-24）

## 本版修复

- WebSocket 预热请求 `generate: false` 交给 CPA 原生路径，保留空输入 `[]`，避免因改成 `null` 而触发 HTTP 400。
- 普通流式请求复制空输入时也保留非 nil 空数组。
- 新增空/非空预热路由、真实动态库空数组和同连接后续生成的回归检查；正式打包要求全部 34 项原生 ABI 用例。
- 预热协议依据 [OpenAI 官方 WebSocket 文档](https://developers.openai.com/api/docs/guides/websocket-mode)。
