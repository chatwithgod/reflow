## 改动范围

- 新增 `fold_started` / `round_finished`，沿用每次独立的 `run_id`；只写白名单数字/枚举，不写请求正文、
  模型名称、身份、headers、回答或不透明推理。停止诊断原有语义保持不变。
- unknown token 为 null，真实 0 为 0。原生生命周期失败可补日志，但只在已经存在的插件状态上记录，
  不把 preempted hook 或 canceled 改成正常完成。
- 离线汇总按 run_id 和轮号，检查缺失、重复、路径冲突及计数一致性，不从时间窗口拼凑请求。
- `usage_join: unavailable` 是刻意保留的限制：用量执行 ID、独立 lifecycle ID、父请求 trace 不是同一个编号。
- 不更改路由、默认模型启发式、续写预算、缓存边界或 HTTP/WS 策略。详见 [诊断说明](DIAGNOSTICS.md)。
