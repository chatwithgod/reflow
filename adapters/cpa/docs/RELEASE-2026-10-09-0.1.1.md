## 原生验收与公开 Windows 字节复验

五平台均在匹配架构的原生 runner 上执行，不把交叉编译当作加载执行：

- Go unit、race、vet、15 秒 decoder fuzz，以及全部 **47 项 Python 回归**通过。
- 每个平台的实际动态库通过 **31 项 C ABI 合成宿主案例**；从 ZIP 实际字节取出的库另重跑同一组 31 项通过。
- 五个平台原库共 **155 次案例执行**，包内库另 **155 次**；是同组案例跨主机重复，不是 310 种独立场景。
- 汇总器核对五个平台同一源码提交/指纹、版本/注册来源、报告、架构、库/包/许可哈希及精确文件布局。
  这是同次可信 CI 报告的验证，不是密码学证明或全面集成认证。

公开下载的 Windows ZIP 另取出 DLL，实读注册信息为 ID `codexreflow`、版本 `0.1.1`、
来源 `https://github.com/LaoPiLao/cpa-plugin-codexreflow`，再运行同一组 **31 项原生离线案例，全部通过**。
该 DLL SHA256：`36c27836f4f6c16ff296b5685cfdc68fc9adabd17421086bd59b0fa0d307f497`。
这次本地复验使用公开下载字节，但仍是合成 ABI 宿主，不是生产安装或实际 WS 握手。

## 限制与商店状态

- **不是五平台全面 CPA/HTTP/WebSocket、真实模型或 Desktop 验收。**
  旧 Windows v0.1.0 的三宿主隔离回归和 dev.5 在线样本不转为新构件的集成证据。
- Linux 构建宿主为 Ubuntu 24.04；任意旧 glibc/musl 发行版、旧 macOS 和签名/公证未验收。
  不承诺所有宿主、客户端、模型/别名、复杂历史、真实取消或重连边界。
- 模型自动选择仍是名称启发式，不是精确同步 CPA 模型目录；精确用量执行 ID 连接仍为 `unavailable`。
- 516 不是降智证明，续接或此次打包更新不保证新增推理、答案质量或消除原始 516 行；
  追加轮次会增加费用和延迟，不要让 CodexComp 与 CodexReflow 同时接管同一模型。
- 商店 [PR #222](https://github.com/router-for-me/CLIProxyAPI-Plugins-Store/pull/222) 于 10 月 9 日关闭、未合并；
  [审核反馈](https://github.com/router-for-me/CLIProxyAPI-Plugins-Store/pull/222#issuecomment-6069997676)要求补齐五平台。
  发布后文档核对时官方注册表仍无 `codexreflow`，尚未重提，不保证后续收录。
